# UXGyan — Lead UX Designer Portfolio

Minimal editorial portfolio homepage built with HTML, CSS and vanilla JavaScript. No build step required.

## Run locally
Open `index.html` in a browser.

## Files
- `index.html` — hero and four-project gallery
- `styles.css` — responsive design system and CSS-built illustrative project artwork
- `script.js` — mobile navigation and current-year footer
- `about.html` — short professional introduction
- `projects/README.md` — placeholder notes for the case studies

## Before publishing
1. Replace illustrative artwork with approved project screenshots.
2. Confirm contact email and add correct LinkedIn URL.
3. Complete the four project pages and verify their links.
4. Verify all experience claims and project descriptions.
5. Clearly label Uber as independent research, not commissioned work.

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
