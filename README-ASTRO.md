# UXGyan — Astro migration

This branch migrates the portfolio to Astro while preserving the approved visual design and existing project interactions.

## Commands

- `npm install` — install dependencies
- `npm run dev` — local development server
- `npm run build` — generate the static site in `dist/`
- `npm run preview` — preview the production build

## Structure

- `src/pages/` — Astro pages for the homepage, About page and four case studies
- `public/` — shared CSS and browser interaction scripts
- `astro.config.mjs` — GitHub Pages base path configuration

The site is deployed to GitHub Pages at `https://gyanart.github.io/uxgyan2/`.
